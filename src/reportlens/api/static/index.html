ReportLens

Ask questions about Canadian companies' annual reports. Every answer cites the pages it came from.

Source on GitHub
What is this?

ReportLens answers questions about the annual reports of RBC, Scotiabank and BCE for fiscal 2021–2024: 12 reports split into about 6,000 passages, plus the headline figures pulled out of their financial tables and a knowledge graph of segments, subsidiaries and executives. It's a portfolio project that puts several retrieval (RAG) techniques side by side, with an evaluation suite measuring what each one adds.

Techniques inside

  • Hybrid searchkeyword and meaning-based search, merged by rank
  • Rerankinga cross-encoder rereads the top 40 passages and keeps the best 5
  • Metadata filters"RBC 2023" in a question limits the search to that report
  • Corrective RAGgrades what it found; rewrites the query if it isn't enough
  • Self-RAGchecks the answer against its sources and revises it
  • Text-to-SQLthe model writes a read-only query over the extracted figures
  • Knowledge graphCypher queries over who runs and owns what
  • Agentic routerpicks the source, and falls back to text search if it fails

Watch the progress panel while it answers: each step appears as it happens. The demo is password-protected and rate-limited because it runs on a free LLM quota. Answers can be wrong; check the cited pages.
